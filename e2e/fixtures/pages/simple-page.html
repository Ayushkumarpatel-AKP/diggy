Rust 1.85 release notes

The Rust team released version 1.85.0 on 20 February 2025. It stabilises the headline Rust 2024 edition and the async closures feature.

Upgrading is a single command: rustup update stable. The release notes list the edition migration guide and the new gen keyword.

  • Rust 2024 edition is now the default for new projects.
  • Async closures are stable.
  • Minimum supported Rust version for the toolchain is 1.82.
